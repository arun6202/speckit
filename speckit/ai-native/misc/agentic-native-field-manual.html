02

The skills that won't go stale

Models, IDEs and pricing churn every quarter. These six are the spine — durable across every role and every tool shift. Build people here, not on seat counts.

D1

Spec-driven thinking

Constraint definition over syntax production. A precise, testable spec is now the unit of work. The market pays for clarity, not typing speed.

D2

Verification & evals

Own the definition of "correct." Write the property tests and oracles the agent must pass. Green is not the same as right.

D3

MCP literacy

The Model Context Protocol is the USB-C for AI — how agents reach tools and data with explicit, audited scopes. Know what's read-only vs. acting.

D4

Orchestration patterns

Delegate → review → own. The progression from one agent, to parallel sessions, to supervised fleets. Reusable skills and prompts are leverage.

D5

Governance & blast radius

RBAC, audit trails, and human-in-loop gates sized to risk. Autonomy is earned per action by how bounded its damage is.

D6

Systems thinking

Architecture, judgment, and knowing what to build remain scarce and human. When syntax is free, the design of the whole is everything.

⚠ Officer's flag · the discipline survives the agent

Generated code earns no exemption from the law. Parse-don't-validate, types as proofs, DUs over classes, Result over exceptions, illegal states unrepresentable, property-based tests. The agent drafts; the officer enforces. Any C#-shaped pattern that surfaces in an F# answer gets a ⚠️ and a rewrite — autonomy does not lower the bar, it raises the value of holding it.

03

Windsurf, as it actually stands

The tool moved under you. Windsurf is now a Cognition (Devin) product — the IDE, the proprietary models, and a cloud agent in one surface. Here's the current shape and how to spend it well.

Windsurf 2.0 + SWE-1.6

Verified June 2026 · Cognition-owned
Model
SWE-1.6 (Apr 7) — ~950 tok/s, roughly 13× faster than Sonnet 4.5. Free / zero-quota tier. Strong on routine multi-file edits and parallel tool calls; lighter on deep reasoning.
Surface
2.0 (Apr 15) — Agent Command Center (Kanban for local + cloud agents), Devin Cloud, Spaces, Codemaps, Fast Context via SWE-grep.
Devin
Cloud + a Rust Terminal CLI + a Local agent shared between IDE and CLI. One harness, three places to run it.
Pricing
Moved off credits to a quota model; Pro ~$20/mo (now level with Cursor). Enterprise carries FedRAMP / HIPAA / ITAR.

How to spend it

Operating guidance
Routine
Default to SWE-1.6 for scaffolding, edits, refactors of a few files — it costs zero quota and the speed is felt in real sessions.
Heavy
Spend quota on Opus 4.7 / GPT-5.5 / Gemini 3 Flash only where reasoning depth earns it — architecture, gnarly bugs, ambiguous specs.
Big jobs
Cascade can crash on ~30-file refactors and offers no partial correction — a wrong turn forces a full restart. Commit before every session; gate large refactors behind review.
Recalibrate your estimator The credits → quota shift breaks the cost model in your Windsurf credit-estimator. Re-base it on quota economics and SWE-1.6's zero-quota tier, or it will mis-price every agentic loop.

# GPT Adoption Roadmap

## Purpose

This diagram shows the actual adoption path from minimal AI usage to governed enterprise reuse.

```mermaid
flowchart LR
  A["Phase 1: Minimal AI Use<br/>Ad hoc help becomes visible"] --> B["Phase 2: Brownfield Understanding<br/>Code, docs, and workflows become markdown"]
  B --> C["Phase 3: Diagrammed Knowledge<br/>Mermaid, C4, and CLLA create shared understanding"]
  C --> D["Phase 4: Workflow Conversion<br/>Repeated prompts become repeatable workflows"]
  D --> E["Phase 5: Skill Promotion<br/>Stable workflows become reusable skills"]
  E --> F["Phase 6: GPT Gems<br/>Trusted patterns become reusable expert assistants"]
  F --> G["Phase 7: Governed Enterprise Reuse<br/>Evidence packs, review, metrics, and continuous improvement"]

  A -. produces .-> A1["Exploration notes"]
  B -. produces .-> B1["Markdown architecture notes"]
  C -. produces .-> C1["Diagram library"]
  D -. produces .-> D1["Workflow specs"]
  E -. produces .-> E1["Skill candidates"]
  F -. produces .-> F1["GPT gem catalog"]
  G -. produces .-> G1["Evidence packs and decision records"]
```

## Operating Notes

- Treat the existing codebase and existing team process as the source of truth.
- Keep every serious AI output reviewable in markdown.
- Use diagrams to clarify decisions, not as decoration.
- Promote only proven workflows into skills and GPT gems.

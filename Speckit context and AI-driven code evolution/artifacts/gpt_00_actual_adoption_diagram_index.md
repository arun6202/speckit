# GPT Actual Adoption Diagram Index

This package is the actual adoption diagram set for moving a brownfield engineering team from light AI usage to serious, governed, reusable AI-assisted delivery.

Every artifact is markdown-first and diagram-source-first. Render Mermaid diagrams in any markdown viewer that supports Mermaid.

## Adoption Rule

Do not begin with automation. Begin with brownfield understanding, capture the reasoning, standardize repeated work, and only then promote stable patterns into reusable skills and GPT gems.
